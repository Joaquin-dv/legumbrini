<h2>📝 Descripción del Proyecto</h2>
<p>
  Este proyecto es una <em>landing page</em> enfocada en presentar una solución alimenticia simple, nutritiva y saludable. Cuenta con una estructura moderna, componentes interactivos y un diseño adaptable a cualquier pantalla.
</p>

<hr />

<h2>📱 Optimización Móvil (Mobile First)</h2>
<p>
  La interfaz fue ajustada minuciosamente para garantizar una excelente experiencia de usuario (UX/UI) en smartphones:
</p>
<ul>
  <li><strong>Título Principal:</strong> Formateado a dos líneas alineadas al centro para evitar cortes abruptos en pantallas pequeñas.</li>
  <li><strong>Iconos de Características:</strong> Separación equilibrada y alineación vertical precisa con respecto a sus etiquetas (<em>Proteínas, Bajo Sodio, Sin Gluten</em>).</li>
  <li><strong>Tipografía y Legibilidad:</strong> Escalado adaptativo con Tailwind CSS para una lectura cómoda.</li>
</ul>

<hr />

<h2>🛠️ Tecnologías Utilizadas</h2>
<ul>
  <li><strong>HTML5:</strong> Estructura semántica del sitio.</li>
  <li><strong>Tailwind CSS:</strong> Framework CSS utilitario para diseño fluido, responsive y estilos modernos.</li>
  <li><strong>JavaScript (ES6+):</strong> Interactividad y lógica del frontend.</li>
</ul>

<hr />

<h2>🎨 Características Visuales</h2>
<ul>
  <li>Sección de propuesta de valor clara y concisa.</li>
  <li>Iconografía descriptiva con bordes redondeados y contraste accesible.</li>
  <li>Galería de productos y fotografía destacada.</li>
  <li>Diseño minimalista enfocado en conversión.</li>
</ul>
